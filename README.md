# ai-skills-prompts

Hermes Agent skills collection (SKILL.md format).

- `skills/software-development/reverse-engineer-anything` — REA (rea-agents 6.5.0): reverse engineer binaries, JS/Electron apps, .NET, WASM, EVM, SQLite via MCP/CLI, with sandbox-specific install workflow (registry tarball + BFS dep installer).
- `skills/note-taking/ai-skills-prompts-sync` — sync this repo into a local Hermes skills tree.

Install into Hermes: copy a skill folder into `~/.hermes/skills/` (or rsync the whole `skills/` tree).
